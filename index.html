01 · Industry Project / ML / Infrastructure

ThermalView — Intelligent Infrastructure Monitoring Console

An industry project developed during my internship at Jio for infrastructure monitoring, thermal analytics, server health and operator workflows.

  • HPE iLO / Redfish discovery and hardware telemetry.
  • Temperature, CPU, power, fan and component-health monitoring.
  • Local supervised thermal forecasting using HistGradientBoostingRegressor.
  • 5/15/30-minute temperature forecasts with time-aware validation and telemetry-based retraining.
  • Prometheus and Grafana observability with Docker deployment.
  • Authentication, TOTP 2FA, alerts, audit logging, scheduling recommendations and backup/recovery.
